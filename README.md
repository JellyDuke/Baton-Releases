# Baton

사용자가 AI 에이전트를 조율하는 Windows 작업실입니다. 이 저장소에는 설치 파일과 업데이트 정보만 공개합니다.

[최신 버전 다운로드](https://github.com/JellyDuke/Baton-Releases/releases/latest)

Windows 64비트용 `.exe` 파일을 내려받아 설치하세요. 업데이트를 지원하는 설치본에서는 **설정 → 업데이트 → 업데이트 확인**으로 새 버전을 확인하고 설치할 수 있습니다.

최근 정식 릴리스 3개의 설치 파일을 보관합니다. 이전 배포 파일을 정리해도 사용자 PC의 대화와 설정은 유지됩니다.

각 릴리스에는 설치 파일, 업데이트 서명, `latest.json`, `SHA256SUMS.txt`가 포함됩니다. 소스 코드는 이 저장소에 포함되지 않습니다.
