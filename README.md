## Baton은 어떤 앱인가요?

Baton은 여러 AI CLI를 **작업 폴더와 채팅방 중심으로 사용하는 Windows 데스크톱 앱**입니다. 에이전트마다 이름·역할·모델·권한을 정하고, 같은 작업방에서 코드 작성과 검토를 맡길 수 있습니다. 대화 옆에서 파일을 편집하고 실행 과정을 읽으며 터미널 명령도 직접 실행합니다.

예를 들어 작성 에이전트에게 구현을 맡긴 뒤 변경 파일을 확인하고, 검토 에이전트에게 다음 작업을 요청할 수 있습니다. 기본은 사용자가 직접 호출하는 방식입니다. 자동 대화와 협업은 작업방 설정에서 켠 경우에만 사용합니다.

> **이 저장소는 공식 설치 파일과 사용 안내를 제공합니다.** Baton 소스는 비공개입니다. 개인·비상업용 사용은 무료이며, 업무용 사용은 별도 허락이 필요합니다. AI·REA 등을 이용한 보호 대상의 추출·복제·재사용·클론 제작은 금지합니다. 정확한 조건과 법률상 예외는 [LICENSE](LICENSE)를 따릅니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| **역할별 AI 에이전트** | 이름·역할·연결할 AI·모델·권한을 정하고 `@에이전트` 또는 호출 대상 선택으로 작업 요청 |
| **프로젝트별 작업방** | 작업 폴더에 연결된 방에서 대화·참여자·작업 맥락을 관리 |
| **실시간 실행 보기** | AI 출력, 도구 사용, 승인 요청, 실행 상태와 변경 파일 확인 |
| **파일 편집과 비교** | 코드 편집·찾기, 실행 전후 파일 비교, 변경 이동·되돌리기 |
| **파일 탐색기** | 파일·폴더를 끌어 같은 작업 폴더 안에서 이동하고 `Ctrl+Z`로 최근 이동 취소 |
| **분할 터미널** | 최대 6개 터미널을 좌우·위아래·격자로 배치하고 작업방별 구성 보관 |
| **이미지와 결과물** | 캡처 붙여넣기·파일 첨부, 이미지·PDF·영상·소리·지원 3D 파일 보기 |
| **채팅 안의 설정** | `/permissions`, `/model`, `/effort` 등으로 호출 권한·모델·사고 수준 선택 |
| **스킬과 MCP** | 에이전트별 스킬·MCP 연결 선택, 계정 연결과 재연결 관리 |
| **내 작업실 꾸미기** | 6개 앱 테마, 편집기 글꼴·테마, 패널 드래그 배치와 화면 배율 조절 |
| **앱 업데이트** | 설정에서 새 버전 확인 후 다운로드·설치, 작업 표시줄·알림 영역 아이콘 지원 |

연결 가능한 공급자는 Claude Code, Codex CLI, Gemini CLI, Qwen Code, OpenCode입니다. 공급자별 모델·권한·이미지·도구 지원 범위는 다르며 설치된 CLI와 계정 상태를 따릅니다. Baton 설치 파일에 AI 모델·구독·사용량은 포함되지 않습니다.

## 이렇게 사용합니다

1. **연결하기** — 사용할 AI CLI를 별도로 설치·로그인한 뒤 Baton의 시작 설정에서 연결합니다.
2. **작업 준비** — 작업 폴더와 작업방을 만들고 작성·검토 등 필요한 에이전트를 초대합니다.
3. **작업 요청** — 에이전트를 선택하거나 `@작성자`로 요청합니다. 새 에이전트는 읽기 전용으로 시작합니다.
4. **결과 확인** — 채팅, 실행 보기와 변경 파일 비교에서 결과를 읽습니다.
5. **다음 작업** — 직접 수정하거나 `@검토자`에게 검토를 요청합니다.

```text
나       → @작성자 설정 화면에 검색 기능을 추가해 줘.
작성자   → 결과와 변경 파일을 제시
나       → 변경 내용을 확인
나       → @검토자 방금 변경한 코드에서 놓친 부분을 찾아 줘.
```

위 예시는 사용 흐름입니다. 에이전트 이름·역할·AI 조합은 직접 정합니다.

## 설치와 업데이트

**[최신 릴리스 열기 →](https://github.com/JellyDuke/Baton-Releases/releases/latest)**

- Windows 64비트용 `Baton_버전_x64-setup.exe`를 내려받아 설치합니다.
- AI CLI와 해당 공급자 계정은 별도로 준비합니다. 변경 기록·되돌리기를 사용하려면 Git도 필요합니다.
- 앱에서 **설정 → 업데이트 → 업데이트 확인**을 누르고 새 버전이 있으면 설치합니다.
- 업데이트 전에는 파일·설정을 저장하고 실행 중인 AI 작업과 터미널을 종료합니다.
- `0.2.0` 이전 설치본이나 개발 실행을 사용했다면 업데이트를 지원하는 설치본을 처음 한 번 직접 설치합니다.

처음 연결하는 과정과 자주 쓰는 조작은 **[처음 시작하기](GETTING_STARTED.md)**에 정리했습니다.

업데이트 서명은 Windows 게시자 인증서와 별개입니다. 공식 릴리스의 파일명·버전과 해시를 확인할 수 있으며, Windows 보안 기능을 끌 필요는 없습니다.

## 데이터와 외부 연결

대화·설정은 로컬 SQLite에, 첨부·스냅샷 등은 앱 데이터 폴더에 보관합니다. 저장 위치는 **설정 → 저장 위치**에서 확인합니다. AI 호출에 사용하는 입력·첨부·맥락과 도구가 읽는 자료는 해당 공급자에 전달될 수 있습니다.

스킬 마켓, MCP, 모델 목록, 업데이트 확인도 각각의 외부 서비스와 통신할 수 있습니다. 오프라인 전용 앱으로 안내하지 않으며, 실제 데이터 흐름은 **[데이터와 연결 안내](DATA_AND_CONNECTIONS.md)**에서 확인할 수 있습니다.

## 현재 단계

Baton은 초기 배포 버전입니다. 주요 기능은 구현되어 있지만 모든 CLI 조합과 실제 사용 환경의 동작을 보장하지는 않습니다. `v0.2.0`은 GitHub의 Windows 빌드·서명·공개 배포를 완료했습니다. 설치 후 UI 동작과 실제 AI 연결은 별도 사용자 확인 대상이며, CPU·RAM 수치는 아직 측정해 제시하지 않습니다.

macOS·Linux 설치본, 창 밖으로 분리하는 패널, 장기 기록·스냅샷의 자동 정리 기능은 현재 제공하지 않습니다.
